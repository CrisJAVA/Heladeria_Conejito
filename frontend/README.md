# Heladería Conejito - Frontend

Este es el módulo frontend para el sistema de la **Heladería Conejito**. El diseño original del proyecto está disponible en [Figma](https://www.figma.com/design/OSUyEeOS7YQlw4DeJra31u/Dise%C3%B1o-web-helader%C3%ADa-familiar).

## Guía de Ejecución del Proyecto

Sigue estos pasos para levantar el servidor de desarrollo del frontend.

### Primera vez (Instalación e Inicio)

Si es la primera vez que descargas o clonas el proyecto, debes instalar todas las dependencias necesarias antes de iniciarlo:

1. Abre una terminal y colócate en la carpeta `frontend`:
   ```bash
   cd frontend
   ```
2. Instala las dependencias necesarias:
   ```bash
   npm install
   ```
3. Inicia el servidor de desarrollo:
   ```bash
   npm run dev
   ```
4. Abre [http://localhost:5173](http://localhost:5173) en tu navegador.

---

### Ejecuciones posteriores (Luego)

Para las siguientes veces que desees ejecutar el proyecto (una vez que ya instalaste las dependencias):

1. Abre una terminal y colócate en la carpeta `frontend`:
   ```bash
   cd frontend
   ```
2. Inicia directamente el servidor de desarrollo:
   ```bash
   npm run dev
   ```
